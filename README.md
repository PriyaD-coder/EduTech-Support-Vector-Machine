# Task 9: Support Vector Machine (SVM)

## Overview
This project demonstrates the implementation of Support Vector Machine (SVM) using both Linear and RBF kernels.

## Objectives
- Understand hyperplane and margins
- Implement Linear and RBF kernels
- Compare kernel performance

## Tools Used
- Python
- Scikit-learn
- NumPy
- Matplotlib

## Dataset
- Iris Dataset

## Implementation Steps
1. Load dataset
2. Preprocess data
3. Train SVM with Linear kernel
4. Train SVM with RBF kernel
5. Evaluate using confusion matrix

## Results
- Linear kernel works well for linearly separable data
- RBF kernel performs better on complex datasets
